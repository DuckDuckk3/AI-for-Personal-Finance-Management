# AI Personal Finance Manager

An AI-powered personal finance management system that helps users track income and expenses, create personal budgets, forecast account balances, and receive intelligent recommendations for better financial management.

## 📌 Introduction

This project aims to develop an **AI-powered personal finance assistant** that helps users manage their personal finances more effectively.

The system can:

* Track income and expenses.
* Automatically categorize financial transactions.
* Forecast account balances based on historical transactions.
* Create and manage personal budgets.
* Provide personalized recommendations for optimizing spending.
* Support users through a conversational financial chatbot.

## 🚀 Key Features

* **Automatic Transaction Categorization**
  Classifies financial transactions automatically using Machine Learning models.

* **Balance Forecasting**
  Predicts future account balances based on historical transaction data.

* **Personal Budget Management**
  Allows users to establish budgets and monitor their spending against predefined limits.

* **AI Financial Chatbot**
  Provides conversational assistance and financial recommendations through a chatbot interface.

## 🔧 Installation & Usage

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/financial-ai.git
cd financial-ai
```

### 2. Install Dependencies

Install the required Python packages:

```bash
pip install -r requirements.txt
```

### 3. Run the System

Run the main application:

```bash
python scripts/main.py
```
